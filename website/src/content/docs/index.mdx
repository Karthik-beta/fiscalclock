fiscalclock is an open-source fiscal calendar engine for Rust, Python and JavaScript. You describe a fiscal calendar as a JSON definition, and the library tells you which fiscal year, quarter, period and week a date falls in. This page is a placeholder; the documentation is being written in the [fiscalclock repository](https://github.com/Karthik-beta/fiscalclock).
