# Command-line interface and MCP server

This folder is reserved for the command-line interface and the Model Context Protocol (MCP) server, planned for version 0.4. Both will expose the same operations as the libraries, with the same names and the same JSON output, and the MCP server will be runnable through the npm and PyPI packages so that agents need no separate install. Nothing is implemented yet; see the [Roadmap](https://github.com/Karthik-beta/fiscalclock/wiki/Roadmap).
