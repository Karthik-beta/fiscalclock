# Brand assets

fiscalclock's logo, icons, social cards and README banner. Every file here is generated by [`design/scripts/build_brand_assets.py`](../../design/scripts/build_brand_assets.py) from the logo geometry, IBM Plex Sans outlines and the [design tokens](../../design/tokens/), and every PNG is rendered by Inkscape. Do not edit these files by hand: change the script or the tokens and rebuild.

| Folder | Contents |
| --- | --- |
| [`logo/`](logo/) | Lockup, symbol and wordmark, each in colour for light backgrounds, colour for dark backgrounds (`-dark`), one colour (`-mono`) and white (`-mono-white`); the symbol's small drawing for 16 to 23 px (`-small`); PNG exports of the lockups and symbols. |
| [`icons/`](icons/) | `favicon.svg` (switches with the colour scheme), `favicon.ico`, the Apple touch icon, web app icons (192, 512, maskable 512), the docs.rs logo and a 512 px registry icon. |
| [`social/`](social/) | The Open Graph card (1200 × 630), the GitHub social preview (1280 × 640) and the background of the Canva card template. |
| [`readme/`](readme/) | The README banner for light and dark themes, plus an opaque PNG fallback for PyPI and npm. |

Where and how to use each file, with its size and the platform rule behind it, is on the wiki's [Asset-Inventory](https://github.com/Karthik-beta/fiscalclock/wiki/Asset-Inventory) page; the rules for the logo are on [Logo-Guidelines](https://github.com/Karthik-beta/fiscalclock/wiki/Logo-Guidelines).

The wordmark is drawn from IBM Plex Sans, which is under the SIL Open Font License 1.1. Terms for using the fiscalclock logo outside this project are **not decided**; until they are, ask the maintainer.
