## Design work

- fiscalclock's visual identity is independent of the maintainer's sibling project workclock. Never reuse workclock's colours, typefaces, logo ideas, tokens, page names or site stack.
- Before designing a logo or any visual asset, load the `frontend-design` skill.
- The maintainer is a software engineer, not a designer: explain each design choice in plain language, define design terms on first use, and state the trade-off.
- `design/tokens/` is the single source of truth for design values, and `assets/brand/` is generated by `design/scripts/build_brand_assets.py`; never edit generated files or exported PNGs by hand. Record design decisions in `design/DECISIONS.md`.
- Ask before pushing to the repository or the wiki, and before saving edits to a Canva design.
