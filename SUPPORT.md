# Getting help

- **Questions** about using fiscalclock or describing your calendar go to [Discussions Q&A](https://github.com/Karthik-beta/fiscalclock/discussions/categories/q-a).
- **Ideas** that are not yet a concrete proposal go to [Discussions Ideas](https://github.com/Karthik-beta/fiscalclock/discussions/categories/ideas).
- **Bugs and wrong results** go to [issues](https://github.com/Karthik-beta/fiscalclock/issues/new/choose), using the matching form.
- **Security problems** are reported privately, as described in [SECURITY.md](SECURITY.md).

The design documents are on the [wiki](https://github.com/Karthik-beta/fiscalclock/wiki).

fiscalclock is maintained by volunteers, so there is no guaranteed response time.
