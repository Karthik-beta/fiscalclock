# Specification

This folder holds the normative contracts that every package implements. [`definition-v1.md`](definition-v1.md) specifies the calendar definition format (spec version 1), and [`api-v1.md`](api-v1.md) specifies the operations, their JSON outputs and the error catalogue. When the code and the spec disagree, the spec is the reference and the disagreement is a bug in one of them; changes to either file need an ADR, as described in [CONTRIBUTING.md](../CONTRIBUTING.md).
